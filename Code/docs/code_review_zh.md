# 修改说明与作者仍需补充的信息

本次已按作者授权修改代码。原始粘贴脚本保留在
`legacy/original_pipeline.py`，新版入口为 `run.py`。

## 已完成的修改

| 原代码问题 | 新版实现 |
| --- | --- |
| 没有随机增强 | 仅训练集使用水平/垂直翻转与 90° 倍数旋转，图像和 mask 完全同步 |
| 只读取预先分好的文件夹，无薄膜分组检查 | 必须提供真实 manifest；检查 28/7/9、film_id 跨集合、文件覆盖和重复 |
| 验证 Dice 先按 batch 平均再平均 | 汇总全部逐图分数后取平均，避免最后一个小 batch 权重偏高 |
| 默认流程没有独立最终测试 | train、evaluate、infer 独立命令；测试加载最佳权重和已保存参数 |
| 测试上比较阈值可能用于选择最优设置 | evaluate 不接受新配置、不搜索最优阈值，使用 checkpoint 中冻结的设置 |
| 阈值比较可能读取人工修正 mask | 新版训练、评估和推理均不调用人工修正 |
| 加载预训练模型失败后自动随机初始化 | 请求 ImageNet 权重却加载失败时直接报错 |
| mask 读取可静默转为 Otsu | 明确选择 red_on_black 或 binary；发现格式不符时报错 |
| 缺少运行记录、独立推理和可导出的结果 | 自动记录配置、环境、划分指纹、历史、逐图/逐薄膜指标、概率及实例图 |
| 原算法与整理版难以区分 | 原始代码归档，修订实现模块化，并在文档中标注新实现的验证范围 |

保持 U-Net++ / ResNet18 / encoder-feature SE / Tversky 的模型设计，默认参数为
512 × 512、batch size 2、50 epochs、AdamW、学习率 1e-3、weight decay 1e-4、
alpha 0.3、beta 0.7、seed 42。

新增增强的具体选择：水平和垂直翻转各以 0.5 概率独立发生，旋转角从
0°/90°/180°/270° 等概率选取。验证与测试集不使用随机增强。
这些概率是本次实现的明确设定，不是从原始脚本发现的历史参数。

默认量化评估使用 0.5 单阈值，后处理在这个语义 mask 上执行。原脚本可视化使用的
滞后阈值也保留为可配置选项，必须在查看最终测试结果前确定。
实例分割保留原概率梯度、形态学边界切割、连通域及局部 watershed 算法。
Dice/IoU 对语义 mask 计算，不能直接作为实例拆分准确率。

## 实验描述仍需要真实记录支持

1. 填入 44 张图像及标注，并根据实际制备记录填写 film_id 和 split。
   程序可以检查分组是否互斥，不能替作者推断哪些图像来自同一张薄膜。
   不要为了满足 28/7/9 的数字把同一薄膜拆入不同集合。
2. 使用新代码实际完成训练与固定参数的独立测试，再更新正文、SI 和回复中的对应
   结果、表格与图像。改写代码本身不能证明既往实验使用了同样的方法。
3. 如果真实薄膜分组与现有 28/7/9 不相容，先据实调整划分与回复，不能伪造分组。
   每个子集还应报告真实的独立薄膜数量。
4. 目前仍是 44 张原始图像。翻转和旋转不会增加独立样本量，也不能替代审稿人希望
   增加独立制备样本的实验。未来扩充计划和当前小样本局限需要保留。
5. 本次未获得原实验权重、完整数据、原环境或训练日志，因此不声称复现了论文分数。
   代码的确定性设置改善可重复性，但不保证不同硬件和软件下逐位相同。

## 新增检查的范围

训练前核查 manifest 和文件，包括测试子集的元数据/文件一致性；训练梯度与选模
仅使用训练/验证数据。测试执行时核对数据与 manifest 指纹，若不同则拒绝继续。
新代码不加载人工修正文件。概率图、mask 和实例图保存在处理后的目标分辨率。
物理晶粒尺寸仍需真实 SEM 标尺和缩放标定。

完成了 7 项行为测试、64 × 64 合成数据 1 epoch 训练/测试/推理以及 512 × 512
前向传播检查；见 verification.md。合成数据仅用于软件验证，不能作为论文数据。
